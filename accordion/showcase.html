Faceless-accordion Showroom

1. Basic (Single Mode)

Only one panel open at a time. Click a trigger to switch.

What is the Faceless pattern?

The Faceless pattern separates logic and state from visual design. The component handles accessibility, animations, and keyboard navigation — styling is entirely up to the consumer.

Do I need a framework?

No. Faceless-accordion is a native Web Component with zero dependencies. It works with any framework or none at all.

How do I control the animation?

Via CSS variables: --accordion-duration and --accordion-easing. Defaults are 300ms and ease.

7. Autoplay

With the autoplay attribute, items cycle automatically. Hover or focus pauses the rotation. Use the ⏸/▶ button to toggle manually.

Slide 1 — Introduction

Autoplay opens each panel in sequence. The timer resets on manual interaction.

Slide 2 — Features

Pauses on hover and focus. Respects prefers-reduced-motion.

Slide 3 — Accessibility

The play/pause button is always keyboard-reachable. aria-live toggles between off (playing) and polite (paused).

Slide 4 — Skipped (disabled)

Disabled items are skipped during auto-rotation.

8. Autoplay with Progress Bar

The CSS variables --accordion-autoplay-interval and --accordion-autoplay-state enable a pure-CSS progress indicator — no JavaScript needed.

Step 1 — Plan

Watch the progress bar on the active trigger. It syncs with the autoplay interval automatically.

Step 2 — Build

The bar resets when the next item opens. Hover to pause — the bar pauses too.

Step 3 — Ship

All driven by animation-play-state: var(--accordion-autoplay-state).

9. Hidden Play/Pause

The hide-play-pause attribute visually hides the button while keeping it accessible to screen readers.

News Item 1

The play/pause button is still in the DOM and reachable via Tab, but visually hidden.

News Item 2

Useful when autoplay is decorative and the button would clutter the design.

News Item 3

Screen reader users can still find and activate it.
