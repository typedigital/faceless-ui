5. A11y Navigation Testing

Tests tab navigation, screen reader landmark skip, and live announcements.

  • Tab — all slides are reachable, even if they are off-screen
  • Focus on an off-screen slide → carousel automatically scrolls into view
  • Screen reader (NVDA: R, VoiceOver: VO+U) → landmark navigation skips the carousel entirely
  • Screen reader: each slide is announced as "Slide N of 6, group"
  • Navigation via arrow keys / dots / buttons → screen reader announces "Slide X of 6"
